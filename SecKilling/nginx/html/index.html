秒杀说明

  • 静态资源：`/index.html`、`/assets/styles.css`、`/assets/app.js` 由 Nginx 直接响应。
  • 动态接口：`/api/products`、`/api/seckill/{productId}` 由 Nginx 代理到两个 Spring Boot 实例。
  • 缓存：商品详情优先走 Redis，并处理穿透、击穿、雪崩。
  • 消息队列：秒杀请求写入 Kafka，再异步创建订单。
